
# Gradebook_groupProject

Description:
This program allows users to manage users students records, in this case been able to add a student, delete a student, listing all students, 
updating students info, and sorting students by ID.



How to run:
option 1) gcc main.c gradebook.c savinginfo.c student_features.c -o gradebook 
./gradebook

option 2)
make
make run


Features:
add students, delete students, update students info, list all students, and sort students by id


input: 
the user decide what input for option and then for id, name , and grade for the student


all data will be save in the file called records.txt and will be saved to used it later.
